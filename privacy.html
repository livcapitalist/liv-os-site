개인정보처리방침

Liv OS(이하 '앱')는 정현지가 자기 삶을 돌보려고 만든 개인용 맥 앱입니다. 이 문서는 앱이 어떤 정보를 읽고, 어디에 두고, 언제 밖으로 보내는지 설명합니다.

1. 앱이 읽는 정보

  • 구글 캘린더 (읽기 전용): 사용자가 직접 연결하고 고른 캘린더의 일정 제목 · 시작과 끝 시각 · 색 · 설명 · 참석 응답 상태. 권한은 calendar.readonly 하나이며, 일정을 만들거나 바꾸거나 지우지 않습니다.
  • 앱에 직접 적은 기록: 묵상 · 기도 · 오늘의 장면 · 약속 · 아이디어 · 프로듀서와의 대화 등.

2. 정보를 두는 곳

  • 모든 정보는 앱을 쓰는 맥의 데이터 폴더에만 저장됩니다. 앱에는 서버가 없고, 만든 사람도 이 정보를 받지 않습니다.
  • 구글 로그인 토큰과 AI 서비스 API 키는 맥의 키체인(macOS 암호화 저장소)으로 잠가 둡니다.
  • 백업도 같은 맥 안에 만들어지며, 사용자가 직접 내보내기를 할 때만 파일로 나옵니다.

3. 밖으로 보내는 경우 (사용자가 켰을 때만)

  • 사용자가 '프로듀서' 기능을 켜고 자기 API 키를 넣었을 때, 앱은 노트와 대화를 만들기 위해 맥에서 바로 Anthropic(Claude) 또는 OpenAI로 정보를 보냅니다.
  • 사용자가 정한 기본값은 전부 보내기입니다: 고른 캘린더의 일정 제목 · 시각 · 색 · 설명 · 장소 · 참석자 이름과 앱에 적은 기록(묵상 · 기도 · 몸 · 돈 · 사람 메모 등). 보내는 범위는 설정에서 끌 수 있고, 처음 보내기 전에 무엇이 가는지 미리 보여 줍니다.
  • API 키 · 토큰 같은 비밀 모양 글과 카드 · 계좌 · 주민등록번호 꼴 숫자는 언제나 가린 뒤 보냅니다.
  • 일정에 붙은 링크는 주소 대신 사이트 이름만 보냅니다. 회의 링크 뒤에 초대 암호가 붙어 있는 일이 많아서입니다.
  • 여럿이 같이 쓰는 채팅 계정에 붙이는 '가린 꾸러미'에는 글(일정 제목 · 이름 · 메모)이 들어가지 않고 시간과 패턴 숫자만 들어갑니다.
  • OpenAI로 보내는 요청은 서비스 쪽에 저장하지 않도록(store: false) 보냅니다. 두 회사 모두 API로 받은 내용을 모델 학습에 쓰지 않는다고 밝히고 있습니다.
  • 그 밖에는 누구에게도 정보를 팔거나 넘기지 않으며, 광고에 쓰지 않습니다.

4. 구글 사용자 데이터 정책 준수

Liv OS가 Google API로 받은 정보를 쓰고 다른 곳으로 옮기는 일은 Google API Services User Data Policy와 그 안의 Limited Use 요구 사항을 따릅니다. 구글 정보는 사용자 자신에게 보여 주는 기능에만 쓰며, 사람이 따로 읽지 않습니다(사용자 본인이 보는 경우 제외).

5. 연결 끊기와 지우기

  • 앱 설정에서 구글 연결을 끊으면 토큰을 구글에 반납하고 지웁니다. 받아 둔 캘린더 사본도 함께 지울 수 있습니다.
  • 구글 계정의 타사 앱 액세스에서도 언제든 권한을 거둘 수 있습니다.
  • 앱을 지우고 데이터 폴더를 지우면 맥에 남은 정보도 사라집니다.

6. 바뀔 때

Privacy Policy

Liv OS is a personal Mac app built by Hyunji Jung for her own use. It is not a public service and it has no server.

Information the app reads

  • Google Calendar, read only (calendar.readonly): titles, start and end times, colors, descriptions and response status of events in the calendars the user connects and selects. The app never creates, edits or deletes events.
  • Notes the user writes in the app.

Where it is stored

Only on the user's own Mac, in the app's data folder. Google tokens and AI API keys are protected with the macOS Keychain. The developer receives none of this data.

When anything leaves the Mac

Only if the user turns on the "producer" feature and enters their own API key: the app then sends, directly from the Mac to Anthropic (Claude) or OpenAI, the information needed to generate notes and chat replies. By the user's choice the default is to send everything (event titles, times, colors, descriptions, locations, attendee names, and notes written in the app); any of it can be turned off in settings, and a preview is shown before the first send. Secret-like strings (API keys, tokens) and card, bank account or national ID numbers are always masked. Links are reduced to the site name, because meeting links often carry passcodes. A redacted packet with numbers only (no titles, names or notes) is offered for chat accounts shared with other people. OpenAI requests are sent with storage turned off. Nothing is sold, shared with anyone else, or used for advertising.

Google API Services User Data Policy

Liv OS's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Disconnecting and deleting

Disconnecting Google in the app's settings revokes and deletes the token, and the local calendar copy can be deleted too. Access can also be removed at any time at myaccount.google.com/permissions.
